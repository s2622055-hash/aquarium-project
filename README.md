# 水族館 順路体験 × 魚ごとの注視割合（Three.js）

順路に沿って水族館を歩く一人称体験と、視線が捉えた魚を判定して「魚ごとの注視割合」を集計する処理です。

## 起動

ES Modules を使うため、ローカルサーバー経由で開いてください（Three.js は importmap で CDN から読み込みます）。

```sh
npm start                      # または: python3 -m http.server 5173
# → http://localhost:5173
npm test                       # 注視計算のユニットテスト
```

## 構成

| ファイル | 役割 |
| --- | --- |
| `src/gazeTracker.js` | 注視判定・集計ロジック（Three.js 非依存、テスト可能） |
| `src/aquarium.js` | 魚種定義・水槽・魚の生成と遊泳 |
| `src/route.js` | 順路（CatmullRom 曲線）と見学スポット |
| `src/main.js` | カメラ移動、視線、遮蔽判定、操作、描画ループ |
| `src/hud.js` | 集計パネルと結果レポート |

## 注視判定の仕組み

毎フレーム以下を行います。

1. **視認**: 30m 以内かつ視錐台内の魚 → 魚種ごとの「視認時間」に加算
2. **候補**: 視線方向との角度から魚の見かけの半径を引いた値が注視コーン（既定 7°）以内
3. **遮蔽**: 角度の小さい順に Raycaster で岩・サンゴ・他の魚に隠れていないか確認
4. **固視**: 同じ個体を 0.15 秒以上見続けたら注視成立（見始めからの時間を遡って加算）

| 指標 | 計算式 |
| --- | --- |
| 注視割合 | 魚種の注視時間 ÷ 全魚種の注視時間合計 |
| 注視率 | 魚種の注視時間 ÷ 魚種の視認時間 |
| 注視被覆率 | 注視時間合計 ÷ 体験時間 |

視線は「画面中央」か「マウスカーソル」から選べます。実際のアイトラッカーを使う場合は、`main.js` の `gazeDir` をその視線ベクトルに置き換えるだけで対応できます。
「自動視線（デモ）」は来館者の視線を模擬するもので、魚種ごとの `appeal` を重みにして見る魚を選びます。

結果は JSON（固視ごとのタイムライン付き）と CSV で保存できます。
